# Intangible Cultural Heritage Multilingual Encyclopedia of the Yangtze River Delta

A multilingual online encyclopedia introducing the intangible cultural heritage of the Yangtze River Delta region.

Supports Chinese, English, Greek, Japanese, and Russian.

## Project Structure

```
APKtouYangtze/
├── apktouyangtze/      # Backend (FastAPI, SQLite)
├── frontend-next/      # Frontend (Next.js)
├── backup/             # Legacy versions based on different tech stacks,
|                         including the 1st version built purely with Flask
|                         and the 2nd version incorporating React for the frontend
└── app.py              # The entry point file for the backend
```
